# A股 AI选股 · Phase142-Test-V1

TDX 真实数据闭环测试版。

## 用途

本测试版用于把已经确定的 A 股五因子研究链路接到本地通达信 `vipdoc` 数据，验证：

`TDX .day → 股票池 → 因子计算 → 综合评分 → Top100`

## 默认数据路径

`D:\new_tdx\vipdoc`

## 当前范围

- A 股股票，不包含基金作为选股对象
- 本地 TDX 数据优先
- 低内存设计，适配 8GB 电脑
- 输出股票池、因子评分、Top100、运行报告
- 不执行真实交易
- 行业 AI、新闻和复杂回测暂不加入测试版

## 注意

GitHub 中保存的是测试版代码与说明；真实 `D:\new_tdx\vipdoc` 数据不会上传。

运行入口计划为 `start.bat`。
